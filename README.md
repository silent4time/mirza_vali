# mirza_vali v1.6.0

Telegram + Bale bot. Apache on port 8091 + domain vhost on 80/443.

## Auto SSL
When you choose own domain (or Reset → option 4), certbot gets Let's Encrypt SSL automatically.

## Install
```bash
curl -fsSL https://raw.githubusercontent.com/silent4time/mirza_vali/main/install.sh | sudo bash
```
