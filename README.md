# mirza_vali

ربات فروش و مدیریت اشتراک VPN برای **تلگرام** و **بله**

**نسخه:** 1.8.75

---

## معرفی

`mirza_vali` یک ربات کامل برای فروش سرویس VPN است که همزمان روی **تلگرام** و پیام‌رسان **بله** کار می‌کند. خرید، پرداخت، تحویل خودکار سرویس، کیف پول و پنل مدیریت ادمین در یک سیستم یکپارچه پیاده‌سازی شده است.

این پروژه بر پایه ربات متن‌باز **میرزا** توسعه یافته و برای استفاده عملی در فروش اشتراک سفارشی شده است.

## روش‌های پرداخت

- **بله‌پی** — پرداخت آنلاین داخل بله؛ از تلگرام نیز با راهنمایی به ربات بله هدایت می‌شود
- **کارت‌به‌کارت** — نمایش شماره کارت، دریافت رسید و تأیید توسط ادمین
- **کیف پول ربات** — خرید مستقیم از موجودی کاربر

تنظیمات پرداخت از پنل مدیریت ربات (تلگرام / بله) انجام می‌شود و بین هر دو پلتفرم هماهنگ است.

## پنل ایلان (Eylan) — نحوه استفاده

پنل ایلان چند پروتکل را روی یک سرور پشتیبانی می‌کند (OpenVPN، WireGuard، L2TP/IPsec، Cisco AnyConnect و حالت ترکیبی Multi).

**نکته مهم:** در ربات، برای **هر نوع VPN باید یک پنل جداگانه** تعریف شود. نباید همه پروتکل‌ها را با یک ردیف پنل بفروشید.

### مراحل پیشنهادی

1. در پنل مدیریت ادمین، برای هر پروتکل یک پنل با نوع **EylanPanel** بسازید.
2. آدرس API و کلید API (همان فیلد رمز پنل) را وارد کنید.
3. در فیلد **Inbound / inboundid** یکی از مقادیر زیر را دقیقاً بنویسید:

| مقدار inboundid | خروجی برای کاربر |
|-----------------|------------------|
| `openvpn` | فایل‌های `.ovpn` + صفحه کاربری |
| `wireguard` | فایل‌های `.conf` (+ QR در صورت پشتیبانی) |
| `l2tp` | سرور، یوزرنیم، رمز، Shared Key (PSK) |
| `cisco` | سرور، یوزرنیم، رمز |
| `multi` | ترکیب پروتکل‌های فعال (OVPN + WG + L2TP + Cisco) |

4. برای هر پنل یک **محصول** جدا بسازید و لوکیشن/پنل همان ردیف را به محصول وصل کنید.
5. اگر روی سرور ایلان چند instance وایرگارد دارید، ربات کانفیگهای موجود را از API می‌گیرد و ارسال می‌کند.

### مثال نام‌گذاری

- پنل: `ایلان OpenVPN` → inboundid = `openvpn` → محصول OpenVPN  
- پنل: `ایلان WireGuard` → inboundid = `wireguard` → محصول WireGuard  
- پنل: `ایلان L2TP` → inboundid = `l2tp` → محصول L2TP  
- پنل: `ایلان Cisco` → inboundid = `cisco` → محصول Cisco  
- پنل: `ایلان Multi` → inboundid = `multi` → محصول Multi  

> اگر فقط یک پنل با inboundid اشتباه یا خالی بسازید، ممکن است همه پروتکل‌ها با هم ساخته شوند یا خروجی نامرتب باشد.

## مسیر نصب

| مورد | مسیر |
|------|------|
| پوشه ربات | **`/home/mirza_vali`** |
| سورس منوی مدیریت | `/opt/mirza_vali-src` |
| فایل تنظیمات نصب | `/etc/mirza_vali/install.env` |

> پیش‌فرض نصب همیشه `/home/mirza_vali` است.

---

## نصب

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/silent4time/mirza_vali/main/install.sh)
```

از منو گزینه **1) Install** را انتخاب کنید.

در طول نصب دامنه ربات، توکن تلگرام، توکن بله و اطلاعات دیتابیس از شما پرسیده می‌شود.

---

## آپدیت

```bash
cd /opt/mirza_vali-src && bash manage.sh
```

گزینه **2) Update**
