# mirza_vali

VPN sales bot — Telegram + Bale

## Current version
**v1.4.0**

## Install on server (one command)

```bash
curl -fsSL https://raw.githubusercontent.com/silent4time/mirza_vali/main/install.sh | sudo bash
```

Then press **1** for Install.

## What to upload on GitHub (repo root)

1. `install.sh` — small installer script  
2. `mirza_vali-latest.zip` — full project (do not extract on GitHub; upload the zip as-is)

Repo: https://github.com/silent4time/mirza_vali

## After each new release

Replace `mirza_vali-latest.zip` with the new zip (keep the same file name) and update `install.sh` if it changed.
