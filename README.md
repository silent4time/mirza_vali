# mirza_vali v1.5.0

VPN sales bot — Telegram + Bale

## Web server
Uses **Apache2** (port **8091**) so it does not conflict with other Apache bots on port 80.
Nginx is not used.

## Install on server

```bash
curl -fsSL https://raw.githubusercontent.com/silent4time/mirza_vali/main/install.sh | sudo bash
```

Press **1** to Install.

## Upload to GitHub (repo root)

1. `install.sh`
2. `mirza_vali-latest.zip` (upload as-is, do not extract on GitHub)
3. `README.md` (optional)
