۱) نصب یک‌خطی روی سرور

روی سرور Ubuntu به‌عنوان root:

curl -fsSL https://raw.githubusercontent.com/silent4time/mirza_vali/main/install.sh | sudo bash
  • منوی مدیریت باز می‌شود → گزینه 1) Install
  • وب‌سرور: Apache (پورت جدا 8091 + دامنه روی 80/443)
  • جداول دیتابیس در نصب ساخته و تأیید می‌شوند
  • php-mysql برای همه نسخه‌های PHP نصب می‌شود
